The study tests a specific receiving boundary for an independently authored fisheries routine. Both prediction paths call the complete, unchanged `R/spm.r` source distributed with MQMF 0.1.5 at commit `f171966258b9dd8d6cdfcc150930cdb45d23cf65`. This is the external source version; the MQMF package is not installed. The reference is a new local native call at the documented teaching arguments, rather than a reproduction of an author's saved 2023 result or original software environment.

The dataset is the author's distributed `data/abdat.RData`: 24 consecutive annual rows from 1985 through 2008, with fields `year`, `catch`, and `cpue`. Catch is reported landed tonnes to the nearest kilogram. The supplied CPUE is an unpublished early standardisation with month, block and diver; its physical unit and normalisation are undocumented. The study preserves that numerical scale and reconstructs neither raw observations nor the standardisation. Annual SE/CV is absent. Bibliographic year/ISBN ambiguity and uncertified upstream rights are retained in THIRD_PARTY.md.

No arbitrary repository registration or platform support is claimed.

Both baseline paths pass `log(c(r=0.4,K=9400,Binit=3400,sigma=0.05))` with `schaefer=TRUE`. Only the active path then selects `r=0.35`; all other supplied values and every code byte remain identical. The unchanged function estimates catchability `q` internally in closed form from positive CPUE and conditional biomass, accepts but ignores `sigma`, and retains its biomass floor of 40. The receiver requires finite non-negative catch and finite positive CPUE for every row, so its stricter input policy is explicit. The function advances one annual step per row. There is no numerical optimisation, new model, biological validation, present-day stock assessment or management advice.

The comparison rule is frozen at absolute `1e-12` and relative `1e-12`, using `abs(a-b) <= max(absolute, relative*max(abs(a),abs(b)))`. It applies to baseline preservation and revised selective-versus-fresh values. At least one active/reference prediction must differ beyond that rule after the growth perturbation. No retry or tolerance widening follows a failure. Agreement establishes within-study calling/preservation only; using the same function in both paths does not validate its model.
