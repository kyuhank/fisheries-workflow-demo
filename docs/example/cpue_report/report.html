CPUE analysis report

Compare annual CPUE indices from the two saved analyses.

Path: Catch and effort rows → adjusted and year-only GLMs → annual index comparison.

Methods

Analysis A fits a quasipoisson GLM with year and cell–quarter effects. Analysis B uses year effects only. Both use a log link and log(hooks / 1000) as an offset. Predictions at 1000 hooks are averaged on the response scale over the same strata with equal weights in every year. Each index is divided by its first-year prediction. The effort filter belongs to analysis A. Released zero counts are retained.

Interpretation

Differences reflect adjustment for cell–quarter composition and any effort filter. The public records aggregate fleet, cell and quarter; vessel identifiers are unavailable. This index describes the selected fleet and released strata. It is a simple workflow example, with no confidence intervals or official stock assessment advice. Absent or suppressed values do not represent zero catch.
