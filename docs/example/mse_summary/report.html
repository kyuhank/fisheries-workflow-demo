Management procedures (MPs)

Three catch rules face the same stock cases, growth scenarios and observation errors.

Constant catch

Keep catch at its recent mean.

Index rule

Scale catch by the three-year mean observed index.

Buffered rule

Apply an index step and 80% catch buffer; limit annual advice changes to 15%.
