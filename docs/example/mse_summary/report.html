Management procedures (MPs)

Three catch rules face the same stock cases, recruitment scenarios and observation errors.

Constant catch

Keep catch at its recent mean.

Index rule

Adjust catch in proportion to the three-year mean observed index.

Buffered rule

Set a stepped catch target from the observed index, apply the 80% buffer, then limit annual advice changes to 15%.
