Assessment report

This report compares the assessment cases using CPUE indices A and B.

Methods

The simple age-structured model uses annual catch and a CPUE index, with fixed biology and constant recruitment. The cases use natural mortality of 0.20 and 0.30 per year.

Results

In 2023, spawning biomass ranged from 0.532 to 0.638 of each case’s unfished level.

Annual catches were reproduced within the numerical tolerance. The fits stayed within the biomass search bounds.

Interpretation

The cases show how CPUE inputs and mortality assumptions carry through to assessment results. Differences between cases are not an uncertainty interval. These synthetic examples provide no stock-management advice.
