Saved workflow example

These outputs were calculated when this version was built. Open them without running code or connecting to the internet.

  1. Data submission — Submit catch and effort records for checking.
  2. Quality check — Check records and return invalid effort for correction.
  3. Prepare and load — Store the accepted records in a fixed database snapshot.
  4. Extract data — Use saved SQL to select observations and annual catches.
  5. CPUE analysis A — Fit a CPUE index with year and vessel effects.
  6. CPUE analysis B — Fit an alternative index with year effects only.
  7. Compare CPUE results — Compare both indices in a plot and table.
  8. CPUE report — Write a short account of the CPUE methods and results.
  9. Prepare inputs A — Join index A to annual catches and check the model inputs.
  10. Prepare inputs B — Join index B to annual catches and check the model inputs.
  11. Assessment A1 — Fit the illustrative model to index A with mortality setting 1.
  12. Assessment A2 — Fit the illustrative model to index A with mortality setting 2.
  13. Assessment B1 — Fit the illustrative model to index B with mortality setting 1.
  14. Assessment B2 — Fit the illustrative model to index B with mortality setting 2.
  15. Compare assessments — Compare the four fitted cases in plots and tables.
  16. Assessment report — Write a short report and preserve its analytical record.
  17. Prepare MSE — Use the four assessment cases to prepare stocks for simulated management trials.
  18. Constant catch — Test a fixed annual catch under the same simulated future conditions.
  19. Index rule — Update annual catch using a simulated abundance index.
  20. Buffered rule — Apply the selected fraction of index-based catch advice, with annual advice changes limited to 15%.
  21. MSE results summary — Compare catch, stock levels and catch stability across the management trials.
  22. MSE report — Report the tested procedures, their trade-offs and the limits of the example.
