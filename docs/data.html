Public albacore data

The Fiji records come from the WCPFC/SPC longline release. Each row is a fleet, quarter and 5° cell aggregate. It is not an individual fishing set or vessel.

1. Extract a small, consistent sample

The source projection contains 662 released Fiji records from 2000–2022. The query selects six cell–quarter strata observed in every year: 132 records through 2021, or 138 through 2022.

Source projection (CSV) · Selection query (SQL)

Read the SQL
-- Published aggregates, not individual fishing sets. Keep the fixed observed support.
SELECT set_id, source_row, year, fleet, quarter, cell, stratum, hooks, catch_n
FROM sets
WHERE fleet = 'FJ' AND hooks > 0 AND catch_n >= 0
  AND stratum IN ('20S_170E_Q4', '20S_175E_Q1', '20S_175E_Q2',
                  '20S_175E_Q3', '20S_175E_Q4', '25S_175E_Q3')
ORDER BY year, cell, quarter, source_row;

2. Standardise catch per effort

CPUE A uses year and cell–quarter stratum with a log effort offset. CPUE B uses year alone. Both quasi-Poisson models predict fish per 1,000 hooks. A averages the same six strata equally in each year; the relative index starts at one in 2000.

3. Keep annual stock catch separate

The yearbook series sums South Pacific albacore across all gears and fleets, in metric tonnes. It is not the catch in the six CPUE strata. Annual catch (CSV).

HHOOKS is hundreds of hooks; the adapter multiplies it by 100. ALB_N counts fish. Confidential cells have masked catch and effort, and are excluded before selection. Their zeros are not observed zero catches. The small fleet index is not validated as stock-wide abundance; assessment and management trials use teaching assumptions.
